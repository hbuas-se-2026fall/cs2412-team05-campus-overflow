## 受访者回复（原文）

> 1. 学生答疑大多在班级微信群、QQ 群，还有线下课间、宿舍当面交流。好处是即时方便，但问题容易被刷走，沉淀不下来，答案也不一定准确。
>
> 2. 正规课程问答平台很有帮助。问题可以长期留存检索，优秀回答能沉淀成学习资源，也方便老师统一查看共性问题，针对性讲解。
>
> 3. 可以设置先审后发、师生举报入口，划定发言规范；违规内容及时删除，对多次违规用户限制发言；同时安排老师或者助教定期巡查。

## 提炼

### 现状与痛点

- **答疑渠道分散**：班级微信群、QQ 群、线下课间、宿舍当面交流
- **优点是即时方便，代价是沉淀不下来**——问题被后续消息刷走，事后无从检索
- **答案准确性无保障**：群聊里的回答没有权威确认机制

### 对平台的价值判断

受访者明确认为「正规课程问答平台很有帮助」，给出三条理由：

1. 问题可以长期留存、可检索
2. 优秀回答能沉淀成学习资源
3. 便于老师统一查看共性问题、针对性讲解

### 治理建议（原 Backlog 未覆盖）

| 建议 | 说明 |
| --- | --- |
| 先审后发 | 内容进入平台前先过审 |
| 师生举报入口 | 使用者可就违规内容举报 |
| 划定发言规范 | 明确什么能说、什么不能说 |
| 违规内容及时删除 | 处置时效要求 |
| 多次违规限制发言 | 分级处置手段 |
| 老师/助教定期巡查 | 常态化的管理动作 |
