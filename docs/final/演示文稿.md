## 一、项目概述

**CampusOverflow** 是一个面向高校课程的校园问答社区平台，解决课堂答疑分散、师生互动不足、优质回答难以沉淀的问题。

| 项 | 说明 |
|---|---|
| 定位 | 校园问答 + 声誉激励 + 内容发现 |
| 交付形态 | 前端 SPA + 后端 REST API + Docker Compose 一键部署 |
| 技术栈 | Spring Boot 3.4（JDK 21）/ Vue3 SPA / MySQL 8（Flyway）/ Redis 7 / GitHub Actions |
| 代码规模 | 27 个 Maven 模块（模块化单体）、4 个限界上下文 |
| 版本基线 | v1.0.0 @ `026f2e5`，develop 默认分支受保护 |

**需求规模**：Product Backlog 25 条用户故事（US-001~US-025），覆盖注册登录、提问回答、投票采纳、声誉徽章、排行榜、中文全文检索、站内通知、悬赏、质量门禁、可观测性、一键部署。

## 二、架构设计

### 2.1 领域驱动设计（DDD）

四个限界上下文，遵循整洁架构分层（api / domain / application / infrastructure / interfaces）：

| 上下文 | 职责 | 关键 US |
|---|---|---|
| Identity 身份与认证 | 注册登录、选课审批、个人资料 | US-001/002/003 |
| Q&A 问答核心 | 提问、回答、采纳、投票、评论、热门标签 | US-004~012 |
| Reputation 声誉与激励 | 声誉结算、徽章、排行榜、悬赏 | US-013~018 |
| Discovery 内容发现 | 中文全文检索、相关推荐、通知 | US-019~022 |

架构决策以 ADR-001~010 记录（模块化单体、事务性发件箱、声誉只追加账本、MySQL ngram 中文检索、跨上下文只经 api 等），详见 `docs/adr/`。

### 2.2 关键架构决策（ADR 亮点）

| ADR | 决策 | 解决的问题 |
|---|---|---|
| ADR-001 | 模块化单体而非微服务 | 课程规模下降低运维与一致性成本 |
| ADR-002 | 事务性发件箱（Outbox） | 跨上下文事件投递与数据库事务一致 |
| ADR-004 | 声誉只追加账本 + 对账 | 积分结算可审计、防篡改 |
| ADR-005 | MySQL ngram 中文全文检索 | 中文分词与搜索质量（`ngram-token-size=2`） |
| ADR-007/008 | 查询侧 OHS/PL（QaQueryApi） | 只读查询不穿透领域模型 |

| 门禁 | 工具 | 说明 |

## 五、部署与可观测性

### 5.1 一键部署（Docker Compose）

```
docker compose -f deploy/docker-compose.yml --profile observability up -d --build
```

组件拓扑：`co-web`(Nginx) → `co-backend`(Spring Boot) → `co-mysql` + `co-redis`；可选 `co-prometheus` + `co-grafana`。compose 通过 healthcheck + depends_on 保证启动顺序，部署后 7 项健康检查全绿（详见 deployment-runbook 第 5 节）。

### 5.2 CI/CD 自动发布

- GitHub Actions：backend → frontend → images（GHCR 推送）→ deploy（SSH 滚动重启 + 冒烟测试）
- `DEPLOY_ENABLED` 开关控制自动部署，未配置服务器时跳过，不给 PR 制造红叉（PR #27/#28）
- 回滚策略：镜像 tag 回退 / git revert（Flyway 迁移不可逆，变更前必须备份）

### 5.3 可观测性

- Prometheus 指标 + 9 条告警规则（含 OutboxBacklogHigh、ReputationLedgerMismatch）+ Alertmanager + Grafana 面板（PR #26）
- 演示：Grafana 可用性/请求率/响应时间曲线、告警规则列表、Actuator 健康/就绪探针

## 六、演示脚本（主流程约 12 分钟）

1. **注册登录**（US-001/002）：注册 → 登录 → 加入课程 CS2001
2. **提问**（US-004）：标题 10–150 字符 + Markdown 正文 + 1–5 标签（含非法输入拒绝演示）
3. **回答与投票**（US-007/009）：第二账号回答、投票 +1 与取消
4. **采纳**（US-008）：提问者采纳最佳回答，每题一次不可更改、越权拒绝
5. **声誉与徽章**（US-013/014/016/017）：采纳 +15 结算、声誉流水、排行榜
6. **可选**：中文搜索（US-019）、相关推荐（US-020）、通知（US-021/022）、悬赏（US-015）、Grafana 监控（US-024/025）

> 演示故障兜底、开场检查单见 `docs/final/demo-script.md` 第 10/11 节。
