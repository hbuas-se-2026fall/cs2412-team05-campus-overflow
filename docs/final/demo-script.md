# CampusOverflow 演示脚本（Demo Script）

> 版本：v1.0（2026-10-30，Lab8 / Sprint 4 最终答辩）
> 依据：`docs/backlog/product-backlog-v1.md`（US-001/002/004/007/008/013/014 + 可选扩展）、`docs/verification/frontend-integration-2026-10-27.md`（联调验证记录）
> 演示时长：主流程约 12 分钟；含可选环节约 18 分钟。
> 前置：按 `docs/final/deployment-runbook.md` 第 9 节完成部署与健康检查；应用以 `prod,demo` profile 启动（`demo` 提供演示数据；正式答辩如需空白环境可在现场注册新账号）。

---

## 0. 演示准备

| 项 | 说明 |
|---|---|
| 演示账号 | 教师 `T2001`（课程 CS2001）、学生 `2023001`；或现场注册新账号 |
| 打开页面 | `http://<演示机IP>/`（生产）或 `http://localhost/`（本机） |
| 备用方案 | 后端 API 文档 `http://localhost:8080/swagger-ui.html`（前端白屏兜底） |
| 监控备查 | Grafana `http://localhost:3000`（admin / 密码见 `.env`） |

## 1. 注册与登录（US-001 / US-002）

**目标**：展示新用户注册、登录、加入课程。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1.1 | 点击页面右上角"注册"（登录页切换），填写用户名（如 `demo_student`）、昵称、邮箱、密码、学院、班级 | 注册成功提示；自动进入登录态或跳转登录页 |
| 1.2 | 使用刚注册的账号登录 | 登录成功，页面显示用户昵称；首页可访问 |
| 1.3 | 进入"我的课程"页面，加入课程 CS2001 | 课程列表出现 CS2001；权限正常（普通学生） |
| 1.4 | （可选）以教师 `T2001` 登录，查看课程管理 | 教师可见课程内学生与教师专属操作 |

**验收对照**：US-001（注册登录）、US-002（加入课程）、US-003（选课审批，可选）。

---

## 2. 提问（US-004）

**目标**：展示创建问题的完整约束。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 2.1 | 点击"提问"（AskPage），输入标题（10–150 字符）、Markdown 正文、1–5 个标签 | 表单校验通过 |
| 2.2 | 输入一个超短标题（<10 字符）提交 | 前端/后端拒绝并提示长度约束 |
| 2.3 | 输入 0 个标签提交 | 提示"至少 1 个标签" |
| 2.4 | 输入合法标题（如"如何理解领域事件与事务性发件箱的关系？"）、正文与标签 `ddd`、`架构` 后提交 | 发布成功，跳转问题详情页，标题/正文/标签完整展示 |

**验收对照**：US-004（标题 10–150 字符、Markdown 正文、1–5 标签）。

---

## 3. 浏览与搜索（US-005 / US-006 / US-019，可选）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 3.1 | 首页问题列表滚动、翻页 | 分页正常，单页 20 条；仅一页时前后按钮禁用 |
| 3.2 | 搜索框输入中文关键词（如 `事务`） | 命中 ngram 中文全文检索，返回相关中文问题（体现 ADR-005） |
| 3.3 | 点击进入一个问题详情 | 显示正文、回答列表、投票数、采纳标记（若有） |
| 3.4 | 详情页底部查看"相关问题推荐" | 出现相关推荐（US-020） |

**验收对照**：US-005/006/019/020。

---

## 4. 回答（US-007）

**目标**：第二账号回答，体现协作。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 4.1 | 切换/登录第二账号（学生 `2023001` 或另注册账号） | 登录成功 |
| 4.2 | 打开演示问题详情，输入回答（Markdown 正文）提交 | 回答发布成功，列表出现新回答；Markdown 正确渲染 |
| 4.3 | （可选）对他人回答投票 +1，再点一次取消 | 第一次投票生效加分，第二次取消；给自己投票不改分并显示错误提示 |

**验收对照**：US-007（回答问题）、US-009（投票 +1/−1、可改投、每内容一票）。

---

## 5. 采纳（US-008）

**目标**：提问者采纳最佳回答，每题一次不可更改。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 5.1 | 切回提问者账号，进入自己的问题详情 | 看到他人回答，可操作"采纳" |
| 5.2 | 点击"采纳"选中回答 | 回答标记为"已采纳/最佳答案"；页面显示采纳状态 |
| 5.3 | 尝试再次采纳另一回答（或重复点击） | 系统拒绝（每题仅一次），提示不可更改 |
| 5.4 | （可选，越权演示）以非提问者账号打开该问题 | 无采纳按钮/操作被拒绝 |

**验收对照**：US-008（采纳一次且不可更改，非提问者禁止）。

---

## 6. 声誉与徽章（US-013 / US-014 / US-016 / US-017）

**目标**：展示声誉自动结算、流水与排行榜。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 6.1 | 回到回答者账号（被采纳的账号），打开"我的声誉/档案" | 声誉分增加（采纳 +15）；流水明细列出"回答被采纳"条目及原因 |
| 6.2 | 查看声誉流水时间戳 | 与采纳操作时间一致（异步结算，事件经发件箱投递，见 ADR-002/004） |
| 6.3 | 打开"排行榜"页（LeaderboardPage） | 周/月/学期榜单展示；被采纳账号排名上升 |
| 6.4 | （可选）展示徽章 | 达到徽章规则的用户显示对应徽章（US-014） |

**验收对照**：US-013（采纳 +15、被赞 +10、被踩 −2、每日上限 200）、US-016、US-017。

## 8. 悬赏（US-015，可选）

|---|---|---|

## 10. 演示故障兜底

| 故障 | 兜底动作 |
|---|---|
| 前端白屏 | 直接打开 `http://<host>:8080/swagger-ui.html`，用 API 演示核心链路（CSRF → 注册 → 登录 → 提问 → 回答 → 采纳） |
| 后端崩溃 | 展示 Grafana 历史曲线 + 本地截图，说明"可观测性正是为此服务"；随后 `docker compose restart backend` |
| 数据库损坏 | `down -v` 重建 + 恢复备份 + 重启（预计 3 分钟，需提前演练） |
| 网络故障（会场 Wi-Fi） | 使用演示机热点；浏览器只留一个标签页 |
